# 🧩 HU-07 - Implementar interfaz de carrito de compras en el frontend

## 📌 Ficha de la historia

- **Título:** Implementar interfaz de carrito de compras en el frontend
- **ID:** HU-07
- **Prioridad:** Must Have (Alta)
- **Rama de desarrollo:** `HU-07-dev`
- **Rama de QA:** `HU-07-qa`

## 👤 Historia de usuario

Como **usuario**,
quiero **gestionar mi carrito desde la interfaz web**,
para **agregar productos, actualizar cantidades, eliminar ítems y ver el total de mi compra**.

## 📖 Descripción

Esta historia implementa en `frontend` la interfaz para gestión del carrito de compras.

Se crean vistas, componentes y servicios para visualizar el carrito, agregar productos, actualizar cantidades, eliminar ítems y mostrar total/subtotales, consumiendo la API a través del `api-gateway`.

## ✅ Criterios de aceptación

- [x] Existe una vista para visualizar el carrito.
- [x] Se pueden agregar productos al carrito desde el frontend.
- [x] Se puede actualizar la cantidad de un ítem.
- [x] Se puede eliminar un ítem del carrito.
- [x] Se muestra el subtotal por ítem.
- [x] Se muestra el total del carrito.
- [x] El frontend consume la API a través del `api-gateway`.
- [x] Se muestran mensajes básicos de éxito o error.
- [x] La interfaz es clara, limpia y funcional.
- [x] No se mezcla lógica de UI con lógica de acceso a API.

## 📦 Entregables esperados

- Vista del carrito.
- Acción para agregar productos al carrito.
- Acción para actualizar cantidades.
- Acción para eliminar ítems.
- Visualización de subtotal y total.
- Servicio de carrito en frontend.
- Componentes reutilizables necesarios.

## 🏁 Definición de terminado

La historia termina cuando el frontend permite gestionar el carrito de compras de forma completa y conectada al sistema a través del gateway.

## ✅ Qué se hizo

- Se creó la página de gestión de carrito: `CartManagementPage`.
- Se crearon componentes reutilizables: `CartSelector`, `AddCartItemForm` y `CartItemsTable`.
- Se creó la capa de acceso a API de carrito: `services/cartService.js`.
- Se creó el hook de lógica de carrito: `hooks/useCartManagement.js`.
- Se agregaron modelo y validaciones de carrito: `models/cartModel.js` y `utils/cartValidators.js`.
- Se integró navegación entre vistas de productos y carrito desde `routes/AppRoutes.jsx`.
- Se implementó cálculo/visualización de subtotal por ítem y total de carrito.
- Se aplicó diseño limpio y responsivo en `styles/carts.css`.
- Se ajustó formato monetario para mostrar valores en COP sin decimales en UI.
- Se mejoró la experiencia visual con feedback automático, confirmación modal y transiciones suaves.

## 🚫 Qué no se hizo

- No se implementó cierre final de integración y despliegue (corresponde a HU-08).

## 🔜 Qué se va a hacer

- Consolidar integración end-to-end final en HU-08.
- Ajustar empaquetado final para ejecución integral del sistema.

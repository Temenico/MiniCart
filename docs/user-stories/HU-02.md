# 🧩 HU-02 - Configurar el módulo de base de datos con Liquibase

## 📌 Ficha de la historia

- **Título:** Configurar el módulo de base de datos con Liquibase
- **ID:** HU-02
- **Prioridad:** Must Have (Alta)
- **Rama de desarrollo:** `HU-02-dev`
- **Rama de QA:** `HU-02-qa`

## 👤 Historia de usuario

Como **equipo de desarrollo**,
quiero **configurar el módulo `database` con PostgreSQL y Liquibase**,
para **tener la base de datos versionada y lista para soportar el sistema**.

## 📖 Descripción

Esta historia busca preparar el módulo `database` como componente independiente del proyecto.

Se debe definir la estructura base de Liquibase, el changelog maestro, la organización de scripts DDL y DML, y la configuración necesaria para ejecutar las migraciones sobre PostgreSQL.

## ✅ Criterios de aceptación

- [x] Existe la carpeta `database` con estructura organizada
- [x] Existe un `changelog-master.yaml`
- [x] Existen carpetas para scripts DDL y DML
- [x] Liquibase está configurado para ejecutarse sobre PostgreSQL
- [x] Se crean las tablas base del sistema mediante migraciones
- [x] Se pueden cargar datos semilla iniciales
- [x] Existe un `README.md` dentro de `database`
- [x] La configuración de base de datos no está mezclada dentro de `cart-service`

## 📦 Entregables esperados

- Estructura del módulo `database`
- Changelog maestro
- Scripts DDL
- Scripts DML
- Configuración de Liquibase
- `README.md` del módulo

## 🏁 Definición de terminado

La historia termina cuando el módulo `database` queda configurado, documentado y con migraciones listas para crear la base del sistema.

## ✅ Qué se hizo

- Se trabajó en la rama `HU-02-dev`.
- Se configuró el changelog maestro en:
  - `database/changelog-master.yaml`
- Se implementaron migraciones DDL con tablas base y reglas de integridad en:
  - `database/01_ddl/changelog-ddl.yaml`
- Se implementaron migraciones DML con datos semilla iniciales en:
  - `database/02_dml/changelog-dml.yaml`
- Se configuró Liquibase para PostgreSQL en:
  - `database/docker/liquibase/liquibase.properties`
- Se agregó script de ejecución manual para Liquibase en:
  - `database/scripts/run-liquibase.ps1`
- Se actualizó Docker Compose para ejecutar `postgres` + `liquibase`:
  - `docker-compose.yml`
- Se actualizó la documentación del módulo:
  - `database/README.md`

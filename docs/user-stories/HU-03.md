# 🧩 HU-03 - Implementar CRUD de productos en el microservicio

## 📌 Ficha de la historia

- **Título:** Implementar CRUD de productos en el microservicio
- **ID:** HU-03
- **Prioridad:** Must Have (Alta)
- **Rama de desarrollo:** `HU-03-dev`
- **Rama de QA:** `HU-03-qa`

## 👤 Historia de usuario

Como **administrador**,
quiero **gestionar los productos del sistema**,
para **crear, consultar, actualizar y eliminar productos disponibles en la tienda**.

## 📖 Descripción

Esta historia implementa en `cart-service` el CRUD completo de productos.

Se crea la entidad `Product`, su repositorio, servicio, controlador, DTOs, validaciones y manejo de errores, dejando listos los endpoints para crear, listar, consultar, actualizar y eliminar productos.

## 📦 Entregables esperados

- Entidad `Product`.
- Repositorio de productos.
- DTOs de productos.
- Servicio de productos.
- Controlador de productos.
- Validaciones.
- Manejo de errores.

## 🏁 Definición de terminado

La historia termina cuando el microservicio permite gestionar productos mediante un CRUD completo y validado.

## ✅ Qué se hizo

- Se implementó la entidad `Product` mapeada a la tabla `product`.
- Se implementó el repositorio `ProductRepository` con Spring Data JPA.
- Se crearon DTOs:
  - `ProductRequest`
  - `ProductResponse`
  - `ErrorResponse`
- Se implementó mapeo entre entidad y DTOs en `ProductMapper`.
- Se implementó servicio de productos:
  - `ProductService`
  - `ProductServiceImpl`
- Se implementó el controlador `ProductController` con endpoints:
  - `POST /products`
  - `GET /products`
  - `GET /products/{id}`
  - `PUT /products/{id}`
  - `DELETE /products/{id}`
- Se agregaron validaciones para:
  - nombre obligatorio
  - precio mayor o igual a 0
  - stock mayor o igual a 0
- Se implementó manejo global de errores con `GlobalExceptionHandler`.
- Se agregaron pruebas en:
  - `ProductControllerTest`
  - ajuste de prueba base en `CartServiceApplicationTests`
- Se ejecutó `mvn test` con resultado exitoso.

## 🚫 Qué no se hizo

- No se implementó CRUD de carritos e ítems (corresponde a HU-04).
- No se implementó integración final de rutas en gateway (corresponde a HU-05).
- No se implementó frontend funcional para productos y carritos (corresponde a HU-06 y HU-07).
- No se implementó cierre integral del sistema end-to-end (corresponde a HU-08).

## 🔜 Qué se va a hacer

# 🧩 HU-04 - Implementar gestión de carritos e ítems en el microservicio

## 📌 Ficha de la historia

- **Título:** Implementar gestión de carritos e ítems en el microservicio
- **ID:** HU-04
- **Prioridad:** Must Have (Alta)
- **Rama de desarrollo:** `HU-04-dev`
- **Rama de QA:** `HU-04-qa`

## 👤 Historia de usuario

Como **cliente**,
quiero **crear y gestionar mi carrito de compras**,
para **agregar productos, actualizar cantidades, eliminar ítems y ver el total de mi compra**.

## 📖 Descripción

Esta historia implementa en `cart-service` la lógica de carritos e ítems.

Se crean las entidades `Cart` y `CartItem`, sus repositorios, servicios, controladores, DTOs y validaciones necesarias para crear carritos, consultar su detalle, agregar productos, actualizar cantidades, eliminar ítems y eliminar carritos.

## ✅ Qué se hizo

- Se implementaron entidades:
  - `Cart`
  - `CartItem`
- Se implementaron repositorios:
  - `CartRepository`
  - `CartItemRepository`
- Se crearon DTOs de carrito e ítems:
  - `AddCartItemRequest`
  - `UpdateCartItemRequest`
  - `CartItemResponse`
  - `CartResponse`
- Se agregó mapeo de respuestas:
  - `CartMapper`
- Se implementó servicio de carrito:
  - `CartService`
  - `CartServiceImpl`
- Se implementó controlador de carritos:
  - `CartController`
- Se agregaron validaciones de negocio para:
  - existencia de carrito
  - existencia de producto
  - cantidad válida
  - stock disponible
  - producto activo
- Se agregó manejo de errores para carrito/ítem inexistente y reglas de negocio:
  - `CartNotFoundException`
  - `CartItemNotFoundException`
  - `BusinessValidationException`
- Se actualizó `GlobalExceptionHandler` para cubrir nuevos casos.
- Se agregaron pruebas de controlador:
  - `CartControllerTest`
- Se actualizó `cart-service/README.md` con endpoints de HU-04.
- Se ejecutaron pruebas exitosas con `mvn test`.

# 🧩 HU-06 - Implementar interfaz de gestión de productos en el frontend

## 📌 Ficha de la historia

- **Título:** Implementar interfaz de gestión de productos en el frontend
- **ID:** HU-06
- **Prioridad:** Must Have (Alta)
- **Rama de desarrollo:** `HU-06-dev`
- **Rama de QA:** `HU-06-qa`

## 👤 Historia de usuario

Como **administrador**,
quiero **gestionar los productos desde la interfaz web**,
para **crear, consultar, actualizar y eliminar productos de forma visual y sencilla**.

## 📖 Descripción

Esta historia implementa en `frontend` la interfaz para gestión de productos.

Se crean vistas, componentes, formularios y servicios para listar, crear, editar y eliminar productos, consumiendo la API a través del `api-gateway`.

## ✅ Criterios de aceptación

- [x] Existe una vista para listar productos.
- [x] Existe una vista o formulario para crear productos.
- [x] Existe una vista o formulario para editar productos.
- [x] Existe acción para eliminar productos.
- [x] El frontend consume la API a través del `api-gateway`.
- [x] Se muestran mensajes básicos de éxito o error.
- [x] Se validan campos requeridos en el formulario.
- [x] La interfaz es clara, limpia y funcional.
- [x] No se mezcla lógica de UI con lógica de acceso a API.

## 📦 Entregables esperados

- Vista de listado de productos.
- Formulario de creación y edición.
- Acción de eliminación.
- Servicio de productos en frontend.
- Componentes reutilizables necesarios.
- Validaciones básicas de formulario.

## 🏁 Definición de terminado

La historia termina cuando el frontend permite gestionar productos de forma completa y conectada al sistema a través del gateway.

## ✅ Qué se hizo

- Se creó la página de gestión de productos:
  - `ProductManagementPage`
- Se crearon componentes reutilizables:
  - `ProductForm`
  - `ProductTable`
  - `FeedbackMessage`
- Se creó capa de acceso a API separada de UI:
  - `services/httpClient.js`
  - `services/productService.js`
- Se creó hook de lógica de productos:
  - `hooks/useProducts.js`
- Se agregaron modelos y validadores:
  - `models/productModel.js`
  - `utils/productValidators.js`
- Se organizó enrutamiento base del frontend:
  - `routes/AppRoutes.jsx`
- Se integró consumo vía gateway (`/api`) con `VITE_API_BASE_URL`.
- Se implementaron mensajes de éxito/error y validaciones de formulario.
- Se aplicó diseño limpio y responsivo en:
  - `styles/products.css`
- Se ajustó el diseño final aprobado para mejor experiencia visual:
  - Ícono de MiniCart integrado en el encabezado principal de la vista.
  - Subtítulo final: **"Crea, actualiza y mantiene tu inventario visible para la tienda."**
  - Modo compacto para pantallas pequeñas de computador, evitando scroll vertical de la página y usando scroll interno solo donde aplica.

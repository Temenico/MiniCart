# 🧩 HU-01 - Configurar base del repositorio y estructura inicial del proyecto

## 📌 Ficha de la historia

- **Título:** Configurar base del repositorio y estructura inicial del proyecto
- **ID:** HU-01
- **Prioridad:** Must Have (Alta)
- **Rama de desarrollo:** `HU-01-dev`
- **Rama de QA:** `HU-01-qa`

## 👤 Historia de usuario

Como **equipo de desarrollo**,
quiero **crear la base del proyecto en un solo repositorio con su estructura inicial**,
para **tener un sistema ordenado, modular y listo para comenzar el desarrollo**.

## 📖 Descripción

Esta historia busca dejar preparada la base técnica del proyecto **MiniCart** dentro del repositorio `minicart`.

Se debe crear la estructura inicial con los módulos:

- `frontend`
- `api-gateway`
- `cart-service`
- `database`
- `docs`

También se deben crear los archivos principales en la raíz, incluyendo un `README.md` completo, `.gitignore` y `docker-compose.yml`.

## ✅ Criterios de aceptación

- [x] Existe un único repositorio llamado `minicart`
- [x] Existen las carpetas `frontend`, `api-gateway`, `cart-service`, `database` y `docs`
- [x] Existe un `README.md` completo en la raíz
- [x] Existe un `.gitignore`
- [x] Existe un `docker-compose.yml` inicial
- [x] La estructura está organizada desde la raíz del repositorio
- [x] No existe una carpeta contenedora extra como `minicart/` o `shopping-cart-app/`
- [x] El frontend inicia con configuración mínima
- [x] El API Gateway inicia con configuración mínima
- [x] El microservicio inicia con configuración mínima
- [x] La estructura del proyecto es limpia y modular

## 📦 Entregables esperados

- Repositorio `minicart`
- Estructura base del proyecto
- Carpeta `database`
- Carpeta `docs`
- `README.md`
- `.gitignore`
- `docker-compose.yml`

## 🏁 Definición de terminado

La historia termina cuando el repositorio tenga la estructura base completa y los archivos principales listos para continuar con la siguiente fase.

## ✅ Qué se hizo

- Se trabajó en la rama `HU-01-dev`.
- Se creó la estructura base del monorepo en la raíz:
  - `frontend/`
  - `api-gateway/`
  - `cart-service/`
  - `database/`
  - `docs/`
